# Infra Project: Terraform + Ansible + Jenkins (2-Node Website Deploy)

CI/CD pipeline that provisions 2 EC2 web nodes with Terraform, configures them with Ansible (Docker + Nginx + static website), and verifies deployment — all orchestrated by Jenkins.

## Architecture

```
Git Push → GitHub → Jenkins EC2 (t3.small)
                      ├── terraform apply  → 2x web EC2 (t3.micro)
                      ├── auto-generate Ansible inventory
                      ├── ansible-playbook → Docker, Nginx, Website
                      └── curl verify
                     ↓
               web-1, web-2  →  http://<public-ip>
```

## Tech Stack

| Tool | Purpose |
|------|---------|
| **Terraform** | Provision EC2, SG, Key Pair |
| **Ansible** | Configure Docker, Nginx, deploy site |
| **Jenkins** | CI/CD pipeline orchestration |
| **AWS** | EC2, VPC, IAM (ap-south-1) |

## Quick Start

### Prerequisites
- AWS account with billing alert
- Jenkins EC2 (t3.small, Ubuntu 24.04, IAM role: `jenkins-lab-role`)
- Terraform, Ansible, Jenkins installed on Jenkins server
- SSH key pair (`ansible-master-key`)

### Manual Run (test before Jenkins)

```bash
# 1. Terraform
cd terraform
terraform init && terraform plan && terraform apply

# 2. Ansible
cd ../ansible
ansible web -m ping --private-key ~/ansible-master-key
ansible-playbook site.yml --private-key ~/ansible-master-key --vault-password-file ~/.vault_pass
```

### Jenkins Pipeline
1. Create Pipeline job → "Pipeline script from SCM" → Git repo URL
2. Add credentials: `ansible-ssh-key` (SSH key), `vault-pass` (Secret file)
3. Build with Parameters → `ACTION: apply`
4. When done: `ACTION: destroy`

## Ansible Concepts Covered
Inventory, ad-hoc commands, playbooks, variables, Jinja2 templates, roles, handlers, register/debug, loops, tags, limit, check/diff, serial, vault, idempotency, ansible-lint, CI/CD integration.

## Important
⚠️ Always run `ACTION: destroy` when done to avoid AWS charges!
